# builtbymo.dev

The Built by Mo studio site. Static HTML, no build step.

- `index.html` - the whole site, one page. Styles are inline in `<head>`.
- Deployed to Cloudflare Pages, auto-deploys on push to `main`.

## Design

Route structure: the page is a journey with five stops, from "where you
are" to "yours entirely." Strip the words out and the structure still
reads as a path with a beginning and an end.

Deliberately no dated content. The "from the bench" asides are fixed
copy and never need updating - an unfed log advertises a practice that
stopped.

## Rules for edits

- No client names, dollar figures, or project timelines. Comparative
  language only ("agency-scale work, without the agency").
- No em-dashes in visible copy.
